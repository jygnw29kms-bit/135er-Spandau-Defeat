# Visual direction standard

Status: **binding art direction and publication rule**.

The public repository does not use AI-generated or low-quality optical-master galleries as a substitute for real engine progress.

## Public image rule

Only the following belong in the public README:
- genuine UE5/Lyra captures from the running UE project
- genuine Source 2/CS2 captures from the running Source 2 project
- clean project diagrams, logos and UI graphics that have passed visual QA

Reference/concept art may be used internally during production, but it stays local unless it has been explicitly reviewed and approved for publication.

## Source 2 production target

- CS2 Workshop Tools / Hammer
- Source 2 PBR materials
- gameplay-readable lighting
- high-detail environment meshes with sensible collision
- recognizable Spandau identity before generic war dressing
- real engine capture as proof of visual progress

## Quality gate

See [IMAGE_QA.md](IMAGE_QA.md). No image is published before full-resolution visual inspection.

## Authenticity rule

Historical presentation must distinguish documented history from fictional gameplay scenarios.
