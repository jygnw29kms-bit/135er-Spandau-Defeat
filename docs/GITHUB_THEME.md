# GitHub visual theme

The repository UI follows the visual language of **135er – Spandau Defeat** while staying within GitHub's supported Markdown/SVG rendering.

## Theme language

- near-black tactical background
- neutral steel-grey typography
- blue team accent: `#22A7FF`
- red team accent: `#E4192C`
- thin HUD/grid lines rather than decorative gradients
- condensed, high-contrast headings
- map/objective terminology consistent with the game
- no fake gameplay screenshots

## Image roles

**Optical master / concept art** may define composition, lighting, atmosphere, HUD language and environmental identity.

**In-game screenshots** must come from the running Unreal Engine project and follow `INGAME_CAPTURE_STANDARD.md`.

The two categories must never be mislabeled.
