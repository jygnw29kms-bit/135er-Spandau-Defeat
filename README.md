# 135er – Spandau Defeat

**Working title:** 135er – Spandau Defeat

A standalone multiplayer first-person shooter centered on the entire Berlin district of **Spandau**, spanning historical eras through the present day.

## Core direction
- Gameplay inspiration: **Day of Defeat Beta 3.1** — fast, direct, class-based objective gameplay, short TTK, readable movement and strong team play.
- Setting: **all of Spandau**, using recognizable real places and historically inspired or present-day variants.
- Real-location focus: Rathaus Spandau, Zitadelle Spandau, Altstadt, Falkenhagener Feld, Bahnhof, Havel crossings, Siemensstadt, Haselhorst, Wilhelmstadt, Staaken, Gatow, Kladow and more.
- Game modes: Flag Capture, Attack/Defend, Territory Control, Demolition/Sabotage and Breakthrough.
- Bots: optional server-fill bots that use the same movement, weapons, objectives, respawn and combat rules as human players.
- Client targets: Windows 10+, Linux x86_64, macOS Intel x86_64.
- Dedicated server: Linux x86_64 only.

## Project goals
1. Preserve the immediate, readable gameplay philosophy of DoD Beta 3.1.
2. Make Spandau itself the visual and thematic identity of the game.
3. Represent the district across multiple eras rather than limiting the game to a single historical period.
4. Keep maps recognizable but compress and adapt routes, cover and sightlines for multiplayer flow.
5. Build bots as full game participants, not scripted dummies.
