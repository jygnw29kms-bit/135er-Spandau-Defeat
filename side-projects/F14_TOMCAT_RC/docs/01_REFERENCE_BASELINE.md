# 01 - Reference baseline

## Geometry authority
Primary geometry shall come from full-scale F-14 technical / three-view references and verified photographs.

Reference order:
1. NASA / technical three-view drawings with known dimensions
2. Grumman / US Navy technical publications where available
3. orthographic museum / archival photography
4. high-quality walkaround photographs for local detail
5. RC manuals only for mechanism and packaging benchmarks

## Scale
Full-size maximum span: 19.545 m.
Model span target at 20 deg: 900 mm.
Scale factor: 900 / 19545 = 0.0460476, approximately 1:21.716.

Using full-size length 19.10 m gives model length about 879.5 mm.
Before OML freeze, exact datum convention (nose probe / airframe reference) must be reconciled across the selected three-view source.

## OML freeze checklist
- nose profile
- canopy and turtledeck
- inlet lips and ramps
- nacelle spacing and cross-sections
- glove leading/trailing geometry
- wing pivot location
- wing planform at 20 deg
- 68 deg swept envelope
- beavertail
- stabilator planform / pivot
- vertical tail cant / position
- nozzle diameter / spacing

No retired R2/R3/R4 project geometry is admissible as a reference.
