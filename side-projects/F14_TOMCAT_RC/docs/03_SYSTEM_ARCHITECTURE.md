# 03 - System architecture

## Propulsion
- 2 x 50 mm EDF
- 4S LiPo common battery bus
- 2 independent ESCs
- separate receiver power strategy preferred over relying on one ESC BEC
- cooling airflow must pass ESC heat sinks without disturbing EDF inlet flow

## Controls
Minimum:
- left/right stabilator
- left/right aileron or equivalent roll authority
- synchronized wing sweep
Optional after mass review:
- rudders
- flaps
- retracts / nose steering

## Wing sweep
- mechanical synchronization preferred
- two independent actuators allowed only with robust electronic matching and jam strategy
- hard mechanical end stops at safe limits
- no printed tooth/root feature carries full flight load without metallic load path

## Structure
- semi-monocoque printed shell
- internal printed frames only where load paths require them
- carbon longerons / spars
- reinforced central wing box
- removable service hatches placed on real panel-line regions when possible

## Assembly
Main modules:
1. nose/cockpit
2. center fuselage + wing box
3. left/right intake/nacelle modules
4. aft fuselage/beavertail
5. left/right variable wings
6. stabilators
7. vertical tails
8. removable electronics/battery hatch
