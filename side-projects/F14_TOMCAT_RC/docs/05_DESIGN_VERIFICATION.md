# 05 - Design verification plan

## CAD verification
- OML overlay against authoritative top/side/front references
- left/right symmetry audit
- wing sweep collision study 20-68 deg
- stabilator clearance
- intake/EDF duct continuity
- service access check
- fastener tool access check

## Structural verification
- wing pivot static load test
- wing-box torsion test
- stabilator pivot pull test
- battery restraint test
- EDF mount vibration test

## Electrical verification
- full-power current measurement
- ESC temperature test
- receiver brownout test
- servo stall-current test
- wing-sweep jam test
- failsafe test

## Flight-test sequence
1. glide / hand-balance checks without power where practical
2. low-power taxi / control verification
3. maiden with wings forward and conservative rates
4. CG refinement
5. progressive speed envelope
6. limited wing sweep at altitude
7. full sweep envelope only after telemetry and control margins are validated
