# Source-defined wing review archives

`F14_v08_GRUMMAN_BASIC_WINGS_SOURCE_REVIEW.f3d` is an actual Fusion archive containing two solid basic F-14 wing lofts built from NASA CR-3992 Appendix 2's original Grumman defining sections. The adjacent PNG is the native Fusion viewport export; the JSON records actual body bounds.

This is a component review document, not the finished F-14 assembly or a printable shell. It retains aircraft FS/WBL/WL coordinates. The nose/body datum transformation is unresolved. The scale sets the two published tip WBL stations at ±450 mm. Native bounds checks confirm bilateral symmetry and 900 mm total span.

The archive was generated and visually inspected on 2026-10-05. Source ordinates, checked OCR repairs and the reproducible importer are stored in the project. Incidence is already part of the source data. No research glove was added. Source-panel span is 301.1736 mm; earlier 319 mm structural screens require reassessment.

Remaining work includes original fuselage component reconstruction, datum registration, wing root/pivot interface, sweep assembly, internal structure, RC integration, print segmentation, and release verification. Do not print these solid review wings as flight parts.
