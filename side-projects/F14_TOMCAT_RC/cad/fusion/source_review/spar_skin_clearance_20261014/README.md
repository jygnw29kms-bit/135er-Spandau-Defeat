# Native continuous spar-to-shell gap review

Ten copied BRep bodies from hashed native source archives, measured with Fusion minimum distance. All twelve same-side pairs have positive clearance; minimum is 0.188973 mm. The nominal 0.2 mm gap fails for upper/lower caps; webs have more than 1.23 mm clearance. These are geometry measurements, not adhesive, strength or manufacturing tolerance qualification.
