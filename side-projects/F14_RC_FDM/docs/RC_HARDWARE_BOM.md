## Radio setup

Recommended channels:
1. Left taileron
2. Right taileron
3. EDF throttle pair
4. Wing sweep
5. Optional left rudder
6. Optional right rudder
7. Optional retracts
8. Spare / telemetry

Use taileron mixing. Wing sweep must use endpoint limits and slow servo movement; the sweep servo must not stall against mechanical end stops.
