# F-14 RC FDM R2 - 3D build plan

## Construction sequence

1. Print and inspect all 17 P2S plates. Reject parts with layer separation, distorted pivot bores or warped join surfaces.
2. Dry-fit fuselage sections 01-05 with the four elliptical reinforcement rings. Insert longitudinal carbon rods before permanent bonding.
3. Assemble the wing box with two M5 steel pivots, pivot doublers/spacers and sweep crank.
4. Mount a >=20-25 kg.cm metal-gear sweep servo. Use equal-length metal pushrods/ball links and mechanical end stops.
5. Bond root, mid and tip wing sections around 5 mm carbon reinforcement. Check left/right mass and straightness.
6. Install two 50 mm EDF units, one ESC per duct and the printed EDF retaining rings.
7. Install one metal-gear servo per all-moving taileron with short, rigid linkages.
8. Install receiver, external BEC and wiring. Keep receiver/antenna wiring away from EDF power wiring where practical.
9. Install the sliding battery tray and 4S 3300-4000 mAh battery. Set battery position from measured CG.
10. Permanently close fuselage modules only after full electrical, linkage and sweep-function tests.
11. Perform servo load test, sweep cycle test, EDF thrust/current test and receiver range test.
12. First flight: wings near extended position, conservative control throws, no full sweep until the airframe is proven.

## R2 geometry status

- 35 exported STL parts.
- 35/35 watertight after mesh processing.
- 35/35 winding-consistent.
- 35/35 within 256 mm in supplied print orientation.
- 17 P2S plate layouts generated as 3MF plus combined STL.

This validates slicing geometry, not flight safety. Physical stiffness, CG, thrust/current, control authority and flutter margin still require prototype testing.
