# P2S R2 plates

17 P2S plate layouts were generated from the checked R2 STL parts.

Each plate exists in the release package as:
- `.3mf` - separate positioned objects for import/slicing
- `.stl` - combined plate geometry as a fallback

The 3MF files are geometry/layout containers. Apply the PETG profile groups documented in `../docs/P2S_PETG_PROFILE.md`.

The complete binary package, individual STLs, 3MF plates and PDF are versioned as R2 release artifacts outside the Source-2 game build path.
