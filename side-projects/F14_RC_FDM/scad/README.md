# OpenSCAD Source

Hier entsteht der parametrische **F-14 R2 RC-Master**.

Geplante Module:
- dimensions.scad
- fuselage.scad
- wing_box.scad
- swing_wing.scad
- intakes_ducts.scad
- nacelles.scad
- tailerons.scad
- vertical_tails.scad
- servo_mounts.scad
- battery_tray.scad
- assembly.scad

STL-Exporte werden erst nach Prüfung in `../stl/` als freigegebene Teile abgelegt.
