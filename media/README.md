# Media

Media is split into two clearly different roles.

## Optical masters

Concept art under `media/maps/` defines visual targets for composition, atmosphere, landmarks, lighting and map identity. These images may be generated or externally rendered but must be identified as **optical master / concept**.

## Source 2 in-game captures

Real gameplay/cinematic captures from the running Source 2 / CS2 project belong under [ingame/](ingame/).

Only those images may be labeled **in-game**.

See [../docs/INGAME_CAPTURE_STANDARD.md](../docs/INGAME_CAPTURE_STANDARD.md).
