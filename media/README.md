# Media

All public imagery for **135er – Spandau Defeat** must come directly from the running Unreal Engine 5.8 project.

Allowed material belongs under [ingame/](ingame/) and must comply with [../docs/INGAME_CAPTURE_STANDARD.md](../docs/INGAME_CAPTURE_STANDARD.md).

Concept art, AI-generated imagery, external renders, mockups and placeholders are not accepted as project media.

The repository uses engine-generated captures only.
