# Map concepts

These images are project concept art / art-direction references for **135er – Spandau Defeat**. They are **not final Unreal Engine screenshots**.

- `map-gallery-concept.jpg` — Rathaus Spandau, Zitadelle, Falkenhagener Feld and Altstadt concept overview
- `zitadelle-spandau-concept.jpg` — fortress combat visual target
- `falkenhagener-feld-concept.jpg` — housing-estate visual target

The final maps target photorealistic Unreal Engine 5.8 environment art using original/licensed assets. Additional map concepts will be added as the remaining core and historical locations move from graybox to art production.
