SpandauStrike

Operation 01 // Flagship Map

Rathaus Spandau

Rathaus Spandau ist die aktuelle Referenzmap. Geometrie, Gameplay, Collision/Nav und Visual QA werden hier zuerst vollständig abgeschlossen, bevor die übrigen Karten wieder in die aktive Produktion zurückkehren.

RATHAUS // MASTER-ALIGNED BUILD

Spandau im Maßstab

Berlin3D/LoD2 und DGM bilden die räumliche Grundlage. Fassaden, Materialien, Rathausplatz, Vegetation und Gameplay-Set-Dressing folgen dem freigegebenen visuellen Master.

Geometry

Real Data First

Vermessene Berliner Daten vor frei erfundener Geometrie. Game-Meshes werden daraus sauber neu aufgebaut.

Gameplay

Combat Pass
