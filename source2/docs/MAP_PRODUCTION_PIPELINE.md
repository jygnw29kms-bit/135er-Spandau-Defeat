# Map production pipeline

For each of the **20 maps**:
1. Reference pass — verify location identity, road/building massing and era-specific details.
2. Gameplay blockout in Hammer — spawns, A/B/C, three strategic lanes, rotations and fallback positions.
3. Bot-safe geometry pass — stairs, ramps, doors, bridges, water edges, clips and no-trap cover placement.
4. Bot validation — 10 bots then 15 bots, three full rounds each, all objectives reachable from both teams.
5. Art pass — Source 2 materials, props, lighting, smoke/atmosphere and map-specific landmark detail.
6. Optimization — visibility, expensive props, lighting and server/client performance.
7. Compile and local playtest.
8. Dedicated server playtest.
9. Genuine in-engine screenshots are captured only after the compiled map runs in CS2.
10. Workshop packaging/publication when the map reaches alpha acceptance.

A map is not accepted because it looks correct alone. It must also pass bot navigation and dedicated-server tests.
