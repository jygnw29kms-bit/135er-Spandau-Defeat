# Server configuration

Portal/PufferPanel fields:
- hostname
- server password
- max players
- Source 2 / Spandau Defeat preset
- start map
- map rotation
- tickets per team
- round duration
- respawn delay
- friendly fire
- start / stop / restart
- console
- backups

Default gameplay values:
- 356 tickets per team
- 30 minute round
- 5 second respawn target
- friendly fire off
- three capture objectives A/B/C
