# Windows client installation — current alpha route

135er – Spandau Defeat currently uses Counter-Strike 2 / Source 2 as its runtime.

1. Install Steam on Windows 10/11 x64.
2. Install Counter-Strike 2 and start it once so Steam completes first-run setup.
3. When the first public Workshop build is published, subscribe to the 135er – Spandau Defeat collection/map package in Steam Workshop.
4. Let Steam finish the Workshop download completely.
5. Start Counter-Strike 2.
6. Join the 135er – Spandau Defeat server from the in-game browser/favorites or via the server address published in the project portal.
7. Workshop maps/addons required by the server are downloaded by Steam/CS2 as supported by the final distribution setup.

The current repository does not redistribute Valve engine/client binaries. Final one-click Workshop/Connect instructions will be added after the first compiled Source 2 map is published.
