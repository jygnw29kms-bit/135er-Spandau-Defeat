# Source 2 / CS2 project

This directory is the active engine workspace definition for **135er – Spandau Defeat**.

## Active basis

- Engine/runtime: Source 2 through Counter-Strike 2
- Authoring: Hammer + CS2 Workshop Tools
- Server target: Linux CS2 dedicated server
- Project milestone: `0.6.0-source2-migration`
- Unreal Engine: retired

## Repository role

This repository tracks original project structure, map definitions, documentation, visual masters and project-owned configuration/code/assets.

Valve-owned Counter-Strike 2 / Source 2 binaries and proprietary game content are not committed here.

## Map set

Current target: **20 maps** — 12 core Spandau maps and 8 historical/special variants.

See [../docs/MAPS_AND_MODES.md](../docs/MAPS_AND_MODES.md).

Do not publish a generated concept as gameplay. Final screenshots labeled **in-game** must be captured from the running Source 2 project.
