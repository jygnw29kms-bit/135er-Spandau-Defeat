# UE5 Spandau Strike Git snapshot

This directory contains the current project-owned UE5 production state for 135er Spandau Strike.

Included: SpandauStrike.uproject, Config, Source, Design, Platforms, Content/SpandauStrike and Content/Python plus project root documentation/runtime helper.

Intentionally excluded: Binaries, Intermediate, Saved, DerivedData, DerivedDataCache, Build, Plugins and SourceData. Generated/cache directories are rebuilt locally. Plugins/Build originate from the Lyra/engine baseline. SourceData contains large/raw GIS source datasets and is not redistributed here; derived project-owned Unreal assets are included under Content/SpandauStrike.

Active production map: /Game/SpandauStrike/Maps/Rathaus/LV_RathausSpandau_REAL_FINAL
Engine: Unreal Engine 5 only.
